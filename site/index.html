  1. Install with Docker. Clone the repository, start Weblab.Network and open the workspace in your browser. Follow the installation guide for the full requirements and commands.
  2. Upload device images. Add an image through the browser and see it become available for a lab.

  6. Inject a link fault. Change a running link's behavior and observe traffic from the PC consoles.

BREAK IT. UNDERSTAND IT. FIX IT.

See how your
network reacts.

Block traffic in one direction or both while a lab is running. Model a silent link failure, watch a protocol converge, and restore traffic when you’re ready.

For supported IOSv, IOL and FRR profiles, cable controls also request a link-down state at the selected endpoint.

Practice, save, share.

Upload supported device images, connect the interfaces and start your lab. Mix device families in the same topology to explore how they work together.

Share a topology as JSON, seed fresh Cisco or FRR devices with initial configurations, or export a stopped lab’s saved device storage as a ZIP. Compact vEOS backups preserve the exact disk while reducing repeated data.
