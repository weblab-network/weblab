# Weblab v0.10.0

Connect lab networks to an IPv4 Internet gateway and document larger topologies
with network clouds, group rectangles and notes.

## Internet gateway

The **Internet** library item provides outbound IPv4 NAT and DNS forwarding
through a dedicated Docker uplink network. Its floating settings window controls
the lab-facing address, return routes and optional Docker uplink subnet.

- Directly connected Alpine PCs with blank addressing fields receive startup
  addressing, a default route and DNS. Explicit PC settings are preserved.
- Routed networks behind FRR use explicit return routes in the gateway settings.
- The gateway accepts replies and blocks unsolicited inbound forwarding. Outbound
  access includes reachable host/LAN destinations; it is not an Internet-only filter.
- Lab-side cables support traffic monitoring and the existing link fault controls.
- With authentication enabled, only administrators create, configure or start
  gateways; writers can stop them. Agent companion networking remains unchanged.

**A locally built gateway helper image is required.** The core release includes
support for the feature, but the installer does not download or build the helper.
No prebuilt gateway image is distributed in this release. See the
[Internet setup guide](https://github.com/weblab-network/weblab/blob/v0.10.0/docs/internet.md)
and [routed FRR example](https://github.com/weblab-network/weblab/blob/v0.10.0/examples/internet-frr.md).

Custom firewall-rule editing, IPv6 Internet forwarding, DHCP, port forwarding
and physical-NIC bridging remain outside this release.

## Network diagrams

**Network cloud** depicts an unmanaged or external network. It uses a plain
cloud outline without an arrow or device card. Inspector edits its name, size
and color. Multiple dashed connections can terminate on its shared drawing
point; they carry no traffic.

**Diagram group** adds a rectangle with a title and notes inside, above or on
its right side. Change its outline color and dimensions in Inspector, or resize
it with its corner handle. Dragging its title or border moves fully enclosed
objects by default; disable **Move enclosed nodes with group** to move the
rectangle alone. Partial overlaps stay put, and resizing or deleting a group
leaves its devices in place. Keyboard controls and Escape cancellation are
supported.

Both objects are diagram-only: no guest images, consoles or processes. They
are skipped by Start lab and Agent start orders. JSON and ZIP preserve their
appearance, notes and settings. See the
[topology guide](https://github.com/weblab-network/weblab/blob/v0.10.0/docs/topology.md).

## Installation and upgrade

Use matching **0.10.0** core, Agent and EXOS image tags. The release provides
`weblab-install.sh` and `SHA256SUMS` for fresh installations. The installer
continues to offer the FRR/LL2S example, optional Agent and authentication;
it is not an upgrade tool.

Back up and stop the lab before recreating existing containers, preserving
their volumes. Existing topologies need no migration. Topologies containing
Internet clouds, network clouds or diagram groups require 0.10.0 or later;
older releases do not recognize these object types.

LL2S remains **0.2.0** and Weblab FRR **10.7.1-wl1**. This release does not
change their binaries or include an OVS STP interoperability fix. See the
[installation guide](https://github.com/weblab-network/weblab/blob/v0.10.0/docs/installation.md).
