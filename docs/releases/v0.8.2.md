# Weblab v0.8.2

A prebuilt installation helper gets a fresh Linux host from Docker to Weblab,
optionally with the Agent and a running FRR/LL2S practice lab. Building from
source with Compose remains supported.

## Fresh-install helper

Download `weblab-install.sh` and `SHA256SUMS` from this release, verify the checksum,
then follow the [installer guide](../installation.md#quick-installer-prebuilt-images).
Run `sudo sh weblab-install.sh --with-agent --start-example` to start the core,
isolated companion, and the preconfigured 12-node VLAN/OSPF/RSTP/VRRP example.
Its instructions are published in the workspace. Omit either flag when unwanted.

The helper uses plain Docker commands, checks the local rootful daemon and host
prerequisites, and refuses existing containers, saved volumes or a busy web port.
It defaults to localhost and preserves a customized `alpine:latest` image.
`--with-auth` enables admin/user/guest accounts with generated keys in a mode-600
file and listens on **0.0.0.0**. This is HTTP on all IPv4 interfaces; use a trusted
network or a separately configured TLS reverse proxy. The optional Agent remains
admin-only when authentication is enabled.
Optional flags select KVM, another name/port, or downloaded exercise files.
It does not install Docker, perform upgrades, install TLS/firewall rules, or
start devices automatically after later restarts. Download size and first boot
requirements still apply; no model weights or proprietary device images are included.

Installation documentation covers both `docker compose` and `docker-compose`,
including the source-build path. The manual no-Compose recipe remains available.
Regression tests cover installer guards, option handling, companion isolation,
example selection and incomplete-installation behavior.

## Existing installations

There is no application configuration migration in this release. Existing users
can follow the usual backup and container-recreation procedure with matching
**0.8.2** core/Agent images; do not rerun the fresh-install helper over saved state.
The EXOS edition receives the matching release tag as well.

LL2S stays at **0.2.0**, and Weblab FRR at **10.7.1-wl1**. Their functionality and
image identity are unchanged. The FRR binary/source archives remain on
[v0.8.0](https://github.com/weblab-network/weblab/releases/tag/v0.8.0).
