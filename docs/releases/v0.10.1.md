# Weblab v0.10.1

This release fixes a workspace reload race and delivers the Internet gateway,
Network cloud and Diagram group features introduced in the v0.10.0 source tag.
The v0.10.0 image/release pipeline stopped at the regression check; use **0.10.1**
for installations. The existing v0.10.0 tag is unchanged.

## Workspace restore fix

When Instructions finished loading after Agent availability was restored, its
saved open state could replace the selected Agent tab in a split workspace.
Split layouts now retain their selected tool while Instructions loads. Standalone
Instructions windows still restore normally. A regression test deliberately
holds the Instructions response until Agent is available to cover this ordering.

## Internet access and topology diagrams

- **Internet** provides outbound IPv4 NAT, DNS forwarding and configurable return
  routes through a dedicated Docker uplink network. A locally built helper image
  is required; the installer does not build or download it.
- **Network cloud** represents an unmanaged network using diagram-only connections.
- **Diagram group** adds rectangles, titles and notes, with optional movement of
  fully enclosed devices. JSON and ZIP preserve diagram settings.

## Installation and upgrade

Use matching **0.10.1** core, Agent and EXOS image tags. The release includes
`weblab-install.sh` and `SHA256SUMS` for fresh installations. Existing installations
should back up and stop the lab before recreating containers, retaining their
volumes. No topology migration is required.

LL2S remains **0.2.0** and Weblab FRR **10.7.1-wl1**. Their binaries and the
Internet helper are unchanged. This release does not add Agent packet-capture
or decoding tools.

See the [installation guide](https://github.com/weblab-network/weblab/blob/v0.10.1/docs/installation.md).
