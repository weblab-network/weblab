Traffic loss leaves interfaces up. Block one direction to model a silent unidirectional fault, or both to drop all frames. These temporary settings are not saved in exports.

Shut down Junos before stopping

    
Junos nodes: 

    
Stopping a running Junos VM can corrupt its filesystem and prevent it from booting again.

    
In each Junos console, save with commit, return to operational mode, then run request system power-off and wait for shutdown to finish. Cancel to return to the consoles.

    
Continue only after guest shutdown. Weblab does not run these commands or verify shutdown for you.

Export lab

    
Topology JSON includes devices, cables, PC network settings and any original startup snippets.

    
JSON + saved configs reads saved Cisco configurations from NVRAM/IOSv disks and FRR configuration files as first-boot snippets for a new lab. Stop the devices first. No console access is needed. Unsaved changes are excluded; this does not save device configurations.

    
JSON + live configs includes unsaved changes by reading current running configurations. Start every Cisco device, leave its console at the privileged (#) prompt and release input locks. Capture locks each console, temporarily suppresses console logging when enabled, and restores the original settings before export. It does not save to NVRAM. Use this option when saved-config retrieval is unavailable.

    
Saved lab ZIP also includes IOL NVRAM and IOSv, EXOS, Arista and Junos disk changes, plus saved FRR configuration. Save device configurations (for example, write memory), then stop the lab before exporting.

    
ZIP backups need the same device images on import. Images, licenses and temporary PC files are excluded. Limit: 8 GiB.

    
    
Console output is recorded on the server, including while browser tabs are closed. Up to 8 MiB of recent output per device is retained, starting with the next device launch after this update. Logs may contain configuration details; review before sharing. Logs are for reading and are not restored into devices.

    

      
      
Reuses matching data from the installed base image. Import requires a Weblab version supporting compact backups; turn off for older installations. All saved disk contents are preserved.

    

    

    

  
  
    
Restore saved lab?

    
This replaces the current topology and saved device state with the selected backup. Export the current lab first if you want to keep it.

    
All devices will remain stopped. The required device images must already be installed and match the backup.
